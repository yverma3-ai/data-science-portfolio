Predicting Dominant Macronutrients in Foods¶

1. Problem Definition¶

The goal of this project is to investigate whether machine learning can predict whether a food is protein-dominant, carbohydrate-dominant, or fat-dominant based on its nutritional characteristics.

The target variable is the dominant macronutrient, which will have three possible categories: protein, carbohydrates, or fat. This makes the project a multiclass classification problem.

Understanding the nutritional characteristics associated with different types of foods can be useful for people interested in nutrition and food composition. This project will explore whether nutritional characteristics such as fiber, sodium, and calories can be used to distinguish between foods with different dominant macronutrients.

Creating the Target Variable¶

The target variable for this project is the dominant macronutrient of each food. To determine this, I converted the grams of each macronutrient into calories. Protein and carbohydrates provide about 4 calories per gram, while fat provides about 9 calories per gram.

For each food, I compared the calories coming from protein, carbohydrates, and fat. Whichever macronutrient contributed the most calories was labeled as that food's dominant macronutrient.

This created three possible classes for the machine learning models: carbohydrates, fat, and protein.

Selecting Features and Avoiding Data Leakage¶

The features selected for the models are fiber, sodium, and calories. Protein, carbohydrates, and fat were not included as predictor variables because they were already used to create the dominant macronutrient target.

Including those variables as features would cause data leakage because the models would be given the same information that was used to determine the correct answer. By excluding them, the models must instead use other nutritional characteristics to predict the dominant macronutrient.

Handling Missing Feature Values¶

Instead of removing foods with missing fiber, sodium, or calorie values, I filled the missing values using the median of each feature. This allowed all 377 foods with complete macronutrient information to remain in the dataset.

The median was used because it is less affected by unusually high or low values than the mean. After this step, there were no missing values in the three features used by the models.
